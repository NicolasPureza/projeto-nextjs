# Projeto 04 — TechStore (Next.js 15)

Aplicação web responsiva de catálogo e loja de tecnologia desenvolvida com **Next.js 15 (App Router)** para a atividade prática do **SENAI**.

## 🚀 Recursos Utilizados do Next.js
- **App Router (`src/app/layout.jsx` e `src/app/page.jsx`)**: Roteamento baseado em arquivos e definição nativa de `metadata` para SEO.
- **Server Components vs Client Components**: Carregamento inicial dos dados no Server Component (`HomePage`) e interatividade com `"use client"` no `CatalogClient`.
- **Componentização e Estado**: Busca em tempo real, filtro por categorias, favoritos e gaveta de carrinho.

## 📦 Como executar
```bash
npm install
npm run dev
```
